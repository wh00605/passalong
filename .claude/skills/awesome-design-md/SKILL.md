# Awesome DESIGN.md library

Source: https://github.com/VoltAgent/awesome-design-md (MIT, see LICENSE).

Each folder in `design-md/` holds one `DESIGN.md` for a real website. Read only the ones you need:

```bash
ls .claude/skills/awesome-design-md/design-md
cat .claude/skills/awesome-design-md/design-md/stripe/DESIGN.md
```

## How to use it

- Study patterns, not identities. Borrow structural ideas (spacing scales, type hierarchy, how cards, nav or pricing are built) and keep the client's own colours, fonts and voice.
- Never reproduce a brand's logo, name, palette-plus-typeface combination or distinctive copy for a different business.
- Good references by job:
  - Calm, trustworthy service sites: `stripe`, `wise`, `intercom`, `cal`
  - Bold editorial or marketing: `framer`, `webflow`, `theverge`, `wired`
  - Clean product UI: `linear.app`, `vercel`, `notion`, `raycast`
  - Warm consumer brands: `airbnb`, `starbucks`, `spotify`
- When writing a DESIGN.md for a project, use these files as format examples.
